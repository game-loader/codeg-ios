# iOS 与 Codeg Server v0.35.1

本次更新基于已有多服务器版本 `3adcec2`，适配合并版 Server `e8cdb776`。iOS 上游 `e2d75f9` 已包含在原分支中；本次无需重复合并上游历史。应用版本保持 1.0.1，构建号更新为 11。

## 会话标签

聊天列表展示所属服务器上的标签，支持任一/全部标签匹配，以及标签创建、改名、颜色和删除。会话详情可添加或移除标签；项目标签沿真实文件夹父链解析到根目录，普通聊天使用全局标签。

每个保留工作区持有独立标签模型和筛选条件，绑定服务器 UUID、配置代次与固定客户端。不同服务器上的相同标签编号不会混用。编辑服务器地址或令牌后，旧弹窗与异步响应不能写入替换后的服务器。更新标签采用增量添加/移除，保留未编辑的标签；会话详情仅刷新标签元数据，保持实时回复、未发送文本和队列。

旧服务器省略 `tag_ids` 时按空列表读取。缺少标签接口时显示升级提示；身份验证、网络和资源错误继续单独显示。

## UI Render

助手回复中的 `spec` 围栏可使用原生布局和图表展示受支持的 UI Render 内容；源文本仍可查看和复制。用户消息、工具输出、普通代码和 RPM spec 文件继续按代码显示。不支持的交互组件或格式保留源文本。

「设置 → AI 与 Agent → UI Render」管理当前服务器上 agent 的 UI Render 技能。设置操作保留发起方服务器与配置代次；服务端返回的失败不会被当作安装成功。

## 断线恢复与失败记录

历史记录中的 `turn_error` 以可选择复制的错误行显示，而不是被当作空消息丢弃。重新连接时读取服务端错误与失败快照，保留诊断信息、重试提示及已解决记录的版本水位；旧连接的失败不能覆盖新连接状态。

终端重新连接后在原服务器查询已有 PTY 快照，恢复缓冲输出并按序号去重，识别断线期间的退出；缺失的终端需要显式重启，不会静默创建新 shell。旧服务器不支持快照接口时会明确提示恢复限制。

## 验证与发布

本地执行便携 Swift 核心测试和语法检查；原生设备编译、iPhone 模拟器 XCTest 以及 Release IPA 由 fork 的 GitHub Actions 执行。具体结果以本次提交对应的 Actions 和 Release 为准。未进行 iPhone/iPad 真机人工交互验收。
